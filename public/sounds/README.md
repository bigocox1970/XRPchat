# Notification Sounds

This directory is for notification sound files used by the XRPChat application.

## Required Files

- `notification.mp3` - Used for new message notifications

## Adding Sound Files

1. Create or download a short notification sound (1-2 seconds)
2. Convert it to MP3 format if needed
3. Name it `notification.mp3` and place it in this directory
4. Restart the application for the changes to take effect

## Recommendations

- Use short sounds (1-2 seconds maximum)
- Ensure the sound is distinctive but not jarring
- Use royalty-free sounds if downloading from the internet
- Test the volume to make sure it's appropriate
