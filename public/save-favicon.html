Save XRPchat QR Logo Favicon

Instructions to Save and Use the Favicon:

  1. Right-click on the QR logo image above
  2. Select "Save Image As..."
  3. Save the file as qr-logo-favicon.png in the public/img/ directory of your project
  4. The HTML file has already been updated to reference this file

The favicon has been set up with these HTML tags:

<link rel="icon" href="/favicon.ico">
<link rel="icon" type="image/png" href="/img/qr-logo-favicon.png">
<link rel="icon" type="image/png" sizes="32x32" href="/img/qr-logo-favicon.png">
<link rel="icon" type="image/png" sizes="16x16" href="/img/qr-logo-favicon.png">

For older browsers that only support .ico format, you may still want to convert this PNG to .ico format using an online converter.
