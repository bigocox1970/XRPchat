How to manually install the favicon:

  1. Download the SVG file using the button above.
  2. Copy the favicon.svg file to your project's root directory or public folder.
  3. Add the following code to your HTML's <head> section: 
    <link rel="icon" type="image/svg+xml" href="/favicon.svg">
  4. If you need support for older browsers, you can convert the SVG to ICO format using an online converter.
