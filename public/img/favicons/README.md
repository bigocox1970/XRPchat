# XRPchat Favicon Instructions

## Creating an ICO file from SVG

To create a favicon.ico file from the SVG:

1. Visit an online SVG to ICO converter such as [Convertio](https://convertio.co/svg-ico/)
2. Upload the `qr-favicon.svg` file
3. Download the converted ICO file
4. Place it in the root directory of your website

## Browser Compatibility

- Modern browsers support SVG favicons (which we've set up in the HTML)
- The ICO format is provided for older browsers and to ensure maximum compatibility
- We've included both formats in the HTML for the best experience across all browsers

## Files Included

- `qr-favicon.svg` - Main SVG favicon
- `qr-favicon-32x32.svg` - 32x32 pixel version
- `qr-favicon-16x16.svg` - 16x16 pixel version
- `favicon-download.html` - A helper page to download these files
