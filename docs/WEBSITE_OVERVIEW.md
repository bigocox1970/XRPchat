# SecureChat Website Overview

## Structure

### Landing Page (Home)
- Hero section with headline: "Secure, End-to-End Encrypted Messaging with XRPL Identity"
- Key features showcase:
  - End-to-end encryption for all messages
  - XRPL wallet-based identity for secure authentication
  - Real-time messaging with instant delivery
  - Dark mode for comfortable viewing
- How it works section explaining:
  - Wallet generation and key management
  - Message encryption process
  - Real-time delivery system
- Call-to-action buttons:
  - "Get Started" (leads to signup)
  - "Go to App" (if logged in)

### Features Page
- Detailed breakdown of security features:
  - End-to-end encryption details
  - XRPL wallet integration
  - Key management system
- User features:
  - Real-time messaging
  - Contact management
  - Profile customization
  - Dark mode support
- Technical features:
  - Built with Vite + React
  - Supabase backend
  - XRPL integration

### Security Page
- In-depth security explanation:
  - Encryption system details
  - XRPL wallet benefits
  - Privacy considerations
- Technical diagrams:
  - Message encryption flow
  - Key management system
  - Security architecture

### FAQ Page
- Common questions about:
  - Getting started
  - Security and privacy
  - XRPL wallet usage
  - Message encryption
  - Account management

## Navigation
- Header:
  - Logo and brand name
  - Dark mode toggle
  - "Go to App" button (top right)
- Sidebar:
  - Home
